## About Me

Tôi là **Software Engineer tại DaiMinh**, tập trung xây dựng các hệ thống backend có kiến trúc rõ ràng, khả năng bảo trì cao và sẵn sàng mở rộng theo nhu cầu nghiệp vụ.

Mối quan tâm chính của tôi nằm ở việc thiết kế phần mềm xoay quanh **business domain** thay vì framework. Tôi nghiên cứu và áp dụng **Clean Architecture**, **Domain-Driven Design (DDD)** và **CQRS** trên nền tảng **.NET**, với mục tiêu tạo ra những kiến trúc đủ chặt chẽ cho hệ thống doanh nghiệp nhưng vẫn giữ được tính đơn giản và thực dụng trong quá trình phát triển.

Hiện tại, tôi tập trung xây dựng các **reference architecture / engineering blueprint** nhằm chuẩn hóa cách tổ chức source code, domain model, application flow và technical boundaries cho các dự án tại DaiMinh.

```text
Architecture       → Clean Architecture · Modular Design · Vertical Slices
Domain             → Domain-Driven Design · Rich Domain Model · Business Rules
Application        → CQRS · Use Cases · Validation · Transaction Boundaries
Backend            → ASP.NET Core · REST APIs · Entity Framework Core
Data               → SQL Server · Relational Modeling · Persistence

Engineering        → Clean Code · SOLID · Testing · Maintainability
````
